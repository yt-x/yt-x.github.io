# 流程: 站点图标定为太阳，并保留位图回退

Status: implemented

## Problem

主页没有站点图标。浏览器即使页面里没有任何 `<link rel="icon">` 也会去请求 `/favicon.ico`，
于是每次打开都在 Console 留一条 404。图标落地时要同时回答三个问题：矢量还是位图、
各槽位放哪张图、颜色是否必须落在站点色板内。

## Decision

- 图案用太阳：金色圆盘 `#E9C46A` 叠 8 条深色 `#2A2A2A` 射线。母版是 `images/favicon.svg`
  （viewBox 48、线宽 3.5、圆头端点），逐字入库。
- `favicon.ico`（16/32/48/64 四档）与 `images/apple-touch-icon.png`（180）由
  `scripts/make-favicon.py` 按同一套几何用 Pillow 位图复刻：本机没有 SVG 光栅化工具，
  母版无法直接栅格化，几何在脚本里再实现一遍，好处是矢量与位图保证同图案。
- 页面声明两个 `rel="icon"`（SVG 在前、ICO 在后）加一个 `apple-touch-icon`。
- apple-touch-icon 垫站点纸色 `#f4f2ec`，铺满整块画布。

## Alternatives considered

1. **只放 SVG，不做位图回退**：省事，但浏览器与爬虫仍旧请求 `/favicon.ico`，404 换个形式回来。放弃。
2. **圆盘去掉描边（平金圆盘）**：16px 下金色面积更大更干净，但深色射线在深色标签栏里几乎不可见，只剩一个金点。放弃。
3. **金色换成站点 accent 洋红 `#db2777`**：与色板一致，但同样有深色射线的对比度问题，且给定方案就是金色。放弃。
4. **给太阳垫底色后用于标签页**：任何标签栏下都清晰，但改变了给定图案的观感。只在 apple-touch-icon 这一格采用。
5. **沿用白文印 S**：自带实底、没有对比度问题，但它会与标签页的太阳形成两套图案。放弃。

## Consequences

- 标签页与 iOS 桌面图标是同一个太阳；Safari 17 以下回退到 `favicon.ico`，图案相同，不会分裂成两套。
- 金色 `#E9C46A` 成为站点色板的明确例外，已记入 `CONSTRAINTS.md`：页面 CSS 仍只用既有 token。
- 位图是生成物：改图案要同时改 `images/favicon.svg` 与 `scripts/make-favicon.py`，
  只改一处会让矢量与位图对不上。
- apple-touch-icon 垫了纸色底，在 iOS 上不会出现透明区被判成黑底、深色射线随之消失的问题。
